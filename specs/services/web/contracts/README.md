# Web Service Contracts

The `web` service is a **consumer** of APIs, not a producer.

It consumes:
- `toy-service` (see `../toy/contracts/openapi.yaml`)
- `trip-service` (see `../trip/contracts/openapi.yaml`)
- `demo-data-init` (see `../demo-data-init/contracts/openapi.yaml`)

It does not expose a public API contract itself.
