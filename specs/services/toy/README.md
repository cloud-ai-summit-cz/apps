# Service Specification README – toy

Use this folder to capture specifications for the Toy service. It manages toy profiles, avatars, and related metadata.

Key files:
- `ARCHITECTURE.md`: Service-specific component view and dependencies; link back to `../../platform/ARCHITECTURE.md`.
- `DATA_MODELS.md`: Schemas owned by the service or extensions of shared models.
- `DEPLOYMENT.md`: Rollout steps and environment-specific notes for this service.
- `OBSERVABILITY.md`: Metrics/logs/traces unique to this service.
- `SECURITY.md`: Threat model and controls specific to this service.
- `TESTING.md`: Local testing strategy for the service.
- `RUNBOOKS.md`: Operational procedures for on-call engineers.
- `contracts/`: API definitions and consumer contracts.
- `decisions/`: Service-specific ADRs.
