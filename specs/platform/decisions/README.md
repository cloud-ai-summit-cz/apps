# Platform Architecture Decisions

This folder contains the "Constitution" of the platform—decisions that apply to all services or define default standards.

## Scope
Platform-level ADRs typically cover:
- Default tech stack and Azure services.
- Protocols and API styles.
- Security and identity baselines.
- Observability, deployment, and testing standards.
